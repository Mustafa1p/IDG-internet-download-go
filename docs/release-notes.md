IDG v1.6.2 - redesigned desktop library

- One command bar for New download, transfer actions and search.
- Grouped navigation with separate Queued, Programs and Images categories.
- Aligned transfer columns, readable filenames and source hosts, and wider state-colored progress bars.
- Selected-download details with destination, status, transferred bytes, speed and segment count; long filenames keep action buttons visible.
- Filename and source-host search, correct active/queued counts, and virtualized transfer rows.
- Roomier 1360 x 860 default window. Compact layouts keep Settings and Download folder visible at 800 x 500, with existing Windows display-scaling support.

Windows x64/x86 installers, portable packages and the matching browser extension are included.

Before/after screenshots and verification: https://github.com/Mustafa1p/IDG-internet-download-go/blob/main/docs/desktop-refresh.md

The transfer engine is unchanged from v1.6.1; previously published benchmarks remain labeled with the measured version. Optional subscription-service music audio retains its documented experimental limitations.
