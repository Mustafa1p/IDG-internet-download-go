Published source: c2d202e; engine: 93e0fde. [v1.6.6](https://github.com/Mustafa1p/IDG-internet-download-go/releases/tag/v1.6.6) is published and its actual assets have been verified. Tagged workflow 42278832284 passed both Windows jobs and publishing.

- Extension unit regressions: 60 pass. Version regressions: two pass. Music protocol/profile regressions: 18 pass.
- Real Edge fixture checks pass for YouTube, X, Instagram and TikTok: natural clicks, hostile page CSS, scroll visibility, removed-button recovery, SPA navigation, visible handoff errors, 60 homepage feed mutations, homepage preview exclusion, and the closed-tab badge race. The package never requests background/*.svg.
- The isolated development build passes five dialog cases (800x500 at 100%, 125%, 150%, 200%; 1280x800 at 100%) and 54 desktop interaction assertions. MP3, MP4 and 480p selection keep the footer clickable. These checks use the development-only preview harness; they do not establish runtime verification of the packaged release window.
- Exact-byte regressions cover interrupted/stalled streams, short-buffer reconnects, permanent failures, validator/range mismatch, pause/resume, concurrent file capacity, cancellation while queued, same/cross-origin credential isolation, connection reuse, POST redirect methods, updater checksums/sizes and response-body timeouts.
- Fresh release CLI engine 93e0fde passes 24/24 local A-D trials. An earlier 27/27 HTTPS integrity run overlapped compilation: its speed timings are not used for a conclusion. A separate isolated comparison of the versioned binary passed 35/35 Rust and 18/18 Node/Python transfers. Rust medians were 55.93 MiB/s for IDG versus 17.70 original IDG, 43.33 curl, 37.97 aria2c and 29.43 Prism. Curl still led the Node test. Raw evidence is retained under target/perf-20261106-*.
- All six published GitHub asset digests match downloaded bytes. Both installers, both portable ZIPs and the extension ZIP pass SHA-256 checks; archive CRCs, PE architecture, source identity, installer version and exclusion of untracked research files pass. Both packaged native hosts return v1.6.6 with the expected capabilities. Reports: target/published-v1.6.6/verified.json and release.json.
- The published extension passes the real Edge fixture suite, including homepage navigation/mutations and closed-tab races. The production updater verifies the actual 115,640,261-byte published x64 installer and reaches progress 1.0; its metadata test confirms the installed build receives no repeat update offer.
- The supplied YouTube URL KE0aEBW2syw passes live MP4/WebM downloads with audio and 480p video, and MP3 conversion with valid MP3 audio. Other source/account-dependent live tests remain unclaimed.

The normal-suite tests do not claim live success for restricted YouTube/social posts or paired music accounts. A persistent website 403 remains an error after bounded retries.
